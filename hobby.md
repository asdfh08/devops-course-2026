# Мой пет-проект
Идея: Телеграм-бот для учёта личных расходов, который принимает суммы через сообщения и записывает их в простую базу данных.
расходов
Стек: Python + база данных SQLite.
Цель: научиться работать с внешними API (Telegram API), проектировать несложные базы данных и сохранять состояние пользователя между запросами.
